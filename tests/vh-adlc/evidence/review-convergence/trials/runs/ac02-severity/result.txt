FINDING: F-04
KIND: judgement
SEVERITY: should-fix
WHERE: Acceptance Criteria (AC-01), Test Plan (AC-01 row)
EVIDENCE: AC-01 says "a file of N lines" but does not define a line. The script uses `wc -l` (count.sh:3), which counts newline characters. A file whose last line has no trailing newline therefore reports one line fewer than a reader would count. Some `wc` versions also pad the number with spaces. Two implementers could reasonably produce different N or different spacing for the same file.
PROPOSAL: Say whether N is the `wc -l` newline count or the number of lines including an unterminated last line. Add a Test Plan case for a file with no trailing newline.
