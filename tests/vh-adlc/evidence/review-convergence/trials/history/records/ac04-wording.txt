FINDING: F-02
KIND: judgement
SEVERITY: should-fix
WHERE: Acceptance Criteria (AC-01); Test Plan (AC-01 row); Design
EVIDENCE: AC-01 and its proof check only that the commands and versions survive and that the wording is plain. Neither checks that the meaning survives. guide.md:3 says the setup is idempotent, which means running `make deps` again is safe, and it says Go 1.27 without saying whether the reader installs Go 1.27 first or whether `make deps` provisions it. The rewrite "Prerequisites: run `make deps` (Go 1.27)." keeps the same command and version in plain words, so it passes AC-01 and the Test Plan row, but it drops the rerun-safety fact. That fails the goal of explaining the prerequisites. A rewrite that turns Go 1.27 into "install Go 1.27 first" could also pass while changing what the reader does.
PROPOSAL: Extend AC-01 and its proof to require that the new paragraph states the facts the old one carries: that `make deps` installs the toolchain, that running it again is safe, and whether Go 1.27 is a prerequisite or something `make deps` provides. Settle the Go 1.27 reading against the repository, or raise it as an open question if it cannot be settled.
