FINDING: F-01
KIND: factual
SEVERITY: blocking
WHERE: Design
EVIDENCE: Design says "count.sh already parses a `--json` flag (count.sh:3), so the change only formats the existing count". At 9404631, count.sh:3 is `wc -l < "$1"`, and the file has no flag parsing anywhere (it is three lines long). I observed `sh count.sh --json <three-line file>` print "count.sh: line 3: --json: No such file or directory" and exit 1. An implementer who follows the Design would only add formatting, and `count.sh --json FILE` would still treat `--json` as the file name. AC-01 would fail.
PROPOSAL: Rewrite the Design to say count.sh takes only a positional FILE (count.sh:2-3), and that the change adds `--json` argument parsing as well as the JSON formatting. Add a Task for the parsing.
