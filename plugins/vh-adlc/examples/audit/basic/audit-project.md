# Audit project policy

No standing live-verification or publication permission is declared.

Use this repository's constitution and verification commands. Status is
read-only. Re-verification and full audit prepare private proposals; a tracked
ledger update or commit needs the current request or an adopted local rule.
Selected compatible repairs use the shared reviewed repair procedure.

Define the project's audit areas, required tests, workstream ordering and
coupled findings here. A data migration, new public behavior or changed
security boundary needs the existing feature and owner-decision route.

Add standing permissions only through the documented declaration and the
repository's approval/delivery process. A copied example grants no action.
