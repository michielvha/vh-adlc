# vh-adlc-docs-impact

For generic requests, select the operation through `references/lifecycle.md`.
Follow `references/docs-impact.md` for setup, scope, checking and accuracy review.
The plugin root is two directories above this skill; resolve its real installed
location rather than guessing a harness cache path. Referenced paths start there.

Input is the repository, requested source/base selection, task-owned metadata
paths and whether the request is report-only or authorizes documentation updates.
Use the plugin pin from `knowledge.md` for an unpinned repository and report that
choice. This operation adds no onboarding files or feature-status gates.
Publication remains subject to `references/authority.md` and the owner's request.
