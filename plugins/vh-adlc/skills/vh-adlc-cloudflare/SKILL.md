# Cloudflare setup

Identify the harness the user wants to connect and read the matching Cloudflare guide:

- [Codex](https://developers.cloudflare.com/agent-setup/codex/)
- [Claude Code](https://developers.cloudflare.com/agent-setup/claude-code/)
- [Copilot CLI](https://developers.cloudflare.com/agent-setup/github-copilot/). Use the CLI instructions on that page.

Use the guide for current installation, configuration, and sign-in instructions. A setup question calls for a walkthrough. When the user asks to install, apply only the selected harness's setup, reuse any existing Cloudflare entry, and verify the connected account with a read-only check.
