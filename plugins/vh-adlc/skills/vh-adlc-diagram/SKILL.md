# Architecture diagram

Read `references/diagram.md` from the installed plugin root before drawing. Use the request, scoped sources and consuming repository instructions to select one useful view. Render in the same request when the sources support it. Ask for the missing information when the main relationship is unresolved.

Use the configured local draw.io Desktop renderer and asset inputs. Follow the reference to draft the evidence brief, author one editable page, validate and inspect the export, then deliver the brief, draw.io file and SVG together.
