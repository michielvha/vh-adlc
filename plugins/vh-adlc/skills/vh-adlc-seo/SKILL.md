# Website SEO assessment

Read `references/seo.md` and `agents/vh-adlc-seo.agent.md` from the plugin root,
two directories above this skill. Read the adopter's SEO adapter if it has one.
Keep its domains, markets and publication rules outside the shared package.

Resolve the binary through Bash using `scripts/ensure-vh-adlc.sh`, then use
`knowledge` with the pin in `knowledge.md` for `conventions/documentation.md`,
`conventions/feature-documents.md` and `guides/humanize-prose.md`. Read the returned
pages and report their revision. An SEO assessment is a report, not a software
feature or permission to change a feature's state.

Assess the requested site with the free sources actually accessible. Semrush is
optional; absence or expiry must leave the free-source assessment usable. Save
source evidence and exportable findings at the adopter's authorized destination.
Report unavailable measurements separately from observed problems. Do not create
accounts, purchase access, publish content or change production configuration.
