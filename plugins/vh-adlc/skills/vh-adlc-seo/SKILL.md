# Website SEO assessment

Read `references/seo.md` and `agents/vh-adlc-seo.agent.md` from the plugin root,
two directories above this skill. Read the adopter's SEO adapter if it has one.
Keep its domains, markets and publication rules outside the shared package.

Resolve the verified binary with `scripts/ensure-vh-adlc.sh` through Bash, then
request `conventions/documentation.md`, `conventions/feature-documents.md` and
`guides/humanize-prose.md` with `knowledge`, using the plugin pin in `knowledge.md`.
Read the resolved pages and report their revision. Use the knowledge failure handling
in `references/loop.md`. An SEO assessment is a report, not a software feature, and
changes no feature state.

Every write and every spending decision follows `references/authority.md`: the
assessment writes only its report and exports, and spends Semrush units only under
its paid-API-unit row. Assess the requested site with the free sources actually
accessible. Semrush is optional; absence or expiry must leave the free-source
assessment usable. Report unavailable measurements as coverage gaps, separately
from observed problems. Do not create accounts, purchase access, publish content or
change production configuration.
